Printing text

The print() function displays text in the output. Put the text inside matching single or double quotation marks.

print("Hello, world!")

This program prints:

Hello, world!

The quotation marks are part of the Python code, but are not printed. Spaces, punctuation, and capital letters inside the quotation marks appear exactly as written.

Writing a program

Write one statement per line. A comment starts with # and does not produce output.

# Display a greeting
print('Welcome!')

Common errors

  • Use matching quotation marks and close the parentheses.
  • Use straight quotation marks (" or '), rather than curly quotation marks.
  • Write print in lowercase.
  • For an exact-output task, print only the requested text, without extra words or spaces.

Idyll tutorial

Build a small interactive article one step at a time. These examples demonstrate the language; adapt the ideas to the requirements in your current task.

1. Write an article

Idyll combines Markdown text with components inside square brackets. Start with a heading and a sentence in the editor.

# Exploring a level

Move the slider to explore how a value changes.

2. Add a variable and a slider

A variable stores a value. Binding a Range component to that variable lets the reader change it. Display shows the current value in the article.

[var name:"level" value:3 /]
# Exploring a level
[Range value:level min:0 max:12 step:1 /]
Current level: [Display value:level /]

Choose Run, read Console output, then open Compiled Article. Drag the slider: the displayed level should change with it. Try both endpoints.

3. Make a calculation reactive

Use a derived value to calculate from the input. Backticks mark an expression to evaluate. Insert the declaration below your variable and the display below your slider.

[derived name:"doubled" value:`level * 2` /]
Doubled level: [Display value:doubled /]

Run again and move the slider. Both the current level and its doubled value should update. If one stays fixed, check the variable name and expression.

4. Add a changing explanation

A Conditional block shows its text when its condition is true. Add these two blocks below the displays, then test levels 5, 6, and 7.

[Conditional if:`level < 6`]Below the midpoint[/Conditional]
[Conditional if:`level >= 6`]At or above the midpoint[/Conditional]

Exactly one message should appear at each value. For your task, use its specified intervals and messages rather than these demonstration boundaries.

5. Try numeric input

When a task calls for a numeric field rather than a slider, bind TextInput to your variable. For example, replace the Range above with:

[TextInput value:level type:"number" min:0 max:12 step:1 /]

Type a number and check the reactive outputs. Multiplication and division handle numeric text in calculations. Keep a Range when the task explicitly requires a slider.

6. Check your work

  1. Use Run and read Console output for errors.
  2. Use Compiled Article to test the controls, calculations, and boundary values.
  3. Use Checks to check the current task's requirements.
  4. Revise and run again; Submit when your task passes.

The Documentation tab provides the full in-platform syntax reference and supported features. Python practice has its own Python tutorial; this tutorial applies to the formal Idyll tasks.

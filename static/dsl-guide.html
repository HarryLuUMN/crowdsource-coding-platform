Idyll

Write article source in the editor and choose Run. Variables, derived expressions and built-in controls update in the interactive preview. Compilation checks markup; expression errors appear when the preview runs. Custom components, data imports and front matter are not available.

[var name:"quantity" value:2 /]
[derived name:"total" value:`quantity * 5` /]
# Cost calculator
[Range value:quantity min:0 max:10 /]
Total: [Display value:total /]
[Conditional if:`quantity > 5`]Bulk order[/Conditional]

Penrose Substance

The editor accepts Substance source. A fixed Domain and Style provide Set and Point objects and the relationships Subset, Disjoint, Intersecting, In and NotIn. Layout uses a fixed variation for repeatability.

Set A, B
Point p
Subset(A, B)
In(p, A)
AutoLabel All

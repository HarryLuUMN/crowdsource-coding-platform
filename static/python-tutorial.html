Python practice tutorial

Learn the coding tool by writing, running, checking, and revising a short Python program. This practice is separate from the formal study tasks.

1. Read the task

Read Task Description on the left. Identify the exact text your program must print, including capital letters, spaces, and punctuation.

2. Write a short program

Click the editor under practice.py. The example below prints a greeting:

print("Hello, world!")

The text goes inside matching quotation marks. For your practice task, replace the example greeting with the message requested in Task Description. Use the Documentation tab for Python syntax and common errors.

3. Run and inspect the output

Click Run. Running lets you test your program without submitting it. Open Console output to read what your program printed. For the example above, you would see:

Hello, world!

Compare your output with the requested message character by character. The quotation marks in your code are not part of the printed output.

4. Review Checks

After inspecting Console output, open Checks to see whether your program prints the requested message. The demonstration greeting above will not pass the practice task unchanged.

5. Revise and run again

If the output differs or a check fails, edit your program and click Run again. Correct spelling, punctuation, and spaces as needed. Run keeps the output tab you were viewing; click Console output or Checks whenever you want to switch.

6. Submit when ready

Once you have verified the output and the check passes, click Submit. Passing the practice task takes you to the formal task and its interface guide. The formal task may use a different programming language.

Follow the independent-work rules throughout. Use the Documentation and Tutorial provided in the tool; do not use outside assistance.

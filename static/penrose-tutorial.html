Penrose tutorial

Describe objects and their relationships in Substance. The platform supplies the Penrose Domain and Style that turn those statements into a diagram.

1. Declare the objects

Set declares sets and Point declares points. Give each object a distinct name. Object names in a relationship must match a declaration.

2. State a relationship

Subset places the first set inside the second. Start with this two-set example:

Set Inner, Outer
Subset(Inner, Outer)
AutoLabel All

Choose Run and read Console output. Then open Visualization: Inner should be inside Outer, and both should have labels. AutoLabel All asks Penrose to label the declared objects.

3. Add a point

In specifies membership; NotIn specifies exclusion. Try a point inside the outer set but outside the inner set:

Set Inner, Outer
Point marker
Subset(Inner, Outer)
In(marker, Outer)
NotIn(marker, Inner)
AutoLabel All

Run again and inspect the point's position. The first argument of In and NotIn is a Point, and the second is a Set.

4. Choose the right relationship

  • Subset(X, Y): X is contained in Y. Argument order matters.
  • Disjoint(X, Y): the sets have no overlap.
  • Intersecting(X, Y): the sets overlap.
  • In(p, X): point p belongs to set X.
  • NotIn(p, X): point p lies outside set X.

Use only the relationships requested by your task, and avoid contradictory requirements such as making the same pair both disjoint and intersecting. These are all supplied by this platform's Domain.

5. Inspect and revise

  1. Use Run, then Console output to review syntax or execution errors.
  2. Open Visualization and check containment, overlap, point placement, and labels.
  3. Open Checks to check the formal requirements. A rendered diagram alone does not establish that every requirement passes.
  4. Correct declarations or relationships, run again, and Submit when the task passes.

If compilation fails, check spelling, declared names, argument types, commas, and parentheses. You edit only Substance here; the Domain and Style are already provided. The Documentation tab contains the runtime reference.
